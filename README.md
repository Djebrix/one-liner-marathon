A single one-line comedy joke, written by a program, for the
[One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2)
competition on make.fun.

## Run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` — deterministic, stdlib only,
no network.
